# Atlas: Light & Polarity

Import `atlas-curseforge-0.2.0.zip` using CurseForge's Import Profile option and sign into your own Minecraft account. It creates an independent Minecraft Java 1.21.1 / Fabric 0.16.14 profile. Java 21 is required. Atlas bundles Fabric API and Rhino. Lithium, FerriteCore and EMI use exact CurseForge project/file references in `manifest.json`; they are optional for the standalone Atlas JAR. A `.mrpack` export is also provided for other compatible launchers.

Create a new world. Press J for the field journal; C dodges, R flips polarity boots, V enables them, G activates Warden Field with upgraded boots. F5 gives free third person, F6 shoulder view, F7 detached camera. O opens Atlas options. Space skips an encounter cinematic.

`/atlas locate fields` finds the Magnetic Fields. Use the centre altar to encounter the Warden. Flank the crystal wards or break them; normal attacks still work. The arena unseals after victory. Sneak-use its altar for a rematch.

`/atlas locate vault` finds a Listening Spire. Descend its spiral staircase, collect armory caches and clear both circuits. After Bell Titan, claim the Sentinel Core and escape by either ascent. With cheats enabled, `/atlas kit` and `/atlas travel fields|vault` give quick access.

This is an alpha vertical slice, not the five-region campaign. Existing worlds need new chunks for generation. Keep backups when choosing to install it into your own instance. Do not stack additional combat, dodge, camera or music replacements without an explicit compatibility adapter. Optional renderer/shader profiles are not included in this initial pack.
